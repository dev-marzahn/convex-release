# Security policy

## Supported versions

Fixes go into the latest release. Upgrade to it before you report.

## Reporting a vulnerability

Don't open a public issue. Report it through [GitHub's private vulnerability reporting](https://github.com/dev-marzahn/convex-release/security/advisories/new) with the version, the steps to reproduce it and what an attacker gains.

## Scope

This covers the `@dev-marzahn/convex-release` package and the `ghcr.io/dev-marzahn/convex-release*` images. Report issues in the Convex backend itself to [Convex](https://github.com/get-convex/convex-backend/security).
